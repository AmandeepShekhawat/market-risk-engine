# Market Data Ingestion Pipeline

API-driven pipeline for ingesting and storing structured datasets

## What it does
- Extracts data from external APIs using yfinance  
- Normalizes and cleans datasets using pandas  
- Loads structured data into PostgreSQL tables  

## Tech Stack
- Python  
- PostgreSQL  
- pandas  

## Focus
- ETL pipelines  
- Data processing  
- Backend systems
